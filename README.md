Basic Concepts of Linux:
        Navigation: 
            Absolute Paths: /
            Relative Paths: ./
            Movement: . / .. / ~ (base) / cd
            List: ls -la  /  pwd
        Files: 
            Make Dir: mkdir -p
            Basic Ops: cp / mv / rm -r / touch
            Read: cat / nano / tail / head / less / grep
        Permissions:
            RWX: read write execute / chmod / chown / sudo
        Process and Environment:
            Process: ps aux / kill <pid> / & (run in background)
            Env: PORT=3000
        Remote:
            ssh: ssh user@host / scp
